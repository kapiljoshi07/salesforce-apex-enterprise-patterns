# Salesforce Apex Enterprise Patterns

An enterprise-oriented Apex architecture demonstrating
modular, reusable and testable Salesforce development.

## Objectives

- Separation of Concerns
- SOLID principles
- Reusable Apex services
- Centralized trigger management
- Testable business logic
- Secure Salesforce development

## Architecture

The project will implement:

1. Trigger Handler Pattern
2. Service Layer Pattern
3. Selector Pattern
4. Domain Layer Pattern
5. Unit of Work Pattern
6. Dependency Injection

## Technology Stack

- Salesforce Platform
- Apex
- Salesforce DX
- Salesforce CLI
- Git and GitHub
